# Contratos

A fonte da verdade fica no repositório, fora desta pasta, para servir também ao agente:

- `docs/contrato-api.md`: rotas, parâmetros, formatos e exemplos.
- `docs/openapi.json`: OpenAPI gerado pelo FastAPI (`python scripts/exportar_openapi.py`),
  verificado por `tests/test_contrato.py`.
